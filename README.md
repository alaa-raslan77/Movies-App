# 🎬 MovieHive – Movies & TV Shows App

MovieHive is a cross-platform Flutter application that allows users to browse popular movies, new releases, and personalized recommendations.
Users can search, filter by categories, manage favorites, and enjoy offline access using local caching.

## 📱 Overview

MovieHive provides a modern and smooth experience for discovering movies and TV shows.
The app integrates TMDB API to deliver rich content while using Firebase and Hive to enhance performance,
personalization, and offline usability.

---

## 🚀 Features

- Browse popular movies
- Discover new releases
- Search movies 
- Filter content by categories
- Add and remove favorites
- Google Sign-In authentication
- Offline access using local caching
- Clean and responsive UI

## 🛠️ Tech Stack

| Category | Technology |
|--------|------------|
| Framework | Flutter |
| Language | Dart |
| State Management | Cubit (BLoC) |
| Backend | Firebase |
| Authentication | Google Sign-In |
| Storage | Firebase Storage |
| Local Cache | Hive |
| APIs | TMDB REST API |
| Version Control | Git & GitHub |

## ⚙️ Setup

### 🧰 Requirements

- Flutter SDK **3.24.3** (stable channel)
- Dart SDK **3.5.3**
- Android Studio (Ladybug or newer)
- Minimum SDK: **23**
- Target SDK: flutter.targetSdkVersion
- Android emulator or physical Android device
